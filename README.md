# 로컬 LLM 비교 프로젝트 학습 공간

사용자가 환경 구성부터 구현·실험·평가·발표까지 직접 진행하고, AI는 설명과 리뷰를 맡는 저장소입니다.

현재는 **후보 조사표를 작성하고, STEP 4의 Python 연결을 준비 중**입니다. [요구사항](docs/requirements.md)과 [모델 조사](docs/models.md)에 작성한 내용을 이어갑니다. 후보 A는 `qwen36-35b-lowvram:latest`를 사용합니다. 사용자 구동 보고와 Ollama 등록 설정을 확인했으며, [Modelfile과 설정 근거](docs/models.md#후보-a-실행-설정-확인)는 외부 학습 폴더에 있습니다. Python 호출 코드·프로젝트 환경, 고정 질문 세트와 실험 결과는 아직 확인되지 않았습니다. 필요한 파일은 해당 단계에서 사용자가 직접 생성합니다.

## 시작하기

1. [프로젝트 발제 원문](docs/project-brief.md)에서 목표와 필수 범위를 확인합니다.
2. [현재 학습 상태](STATE.md)에서 지금 단계와 다음 한 작업을 확인합니다.
3. [단계별 안내](docs/guide.md)를 따라 직접 시도하고, 작성한 코드와 실행 결과를 바탕으로 AI와 대화합니다.

다음 작업은 **사용자가 이 저장소에 Python 3.12 프로젝트 환경을 준비하기**입니다. STEP 2의 필수 통과 조건과 확인 방법은 사용 사례에 맞게 구체화합니다. 현재 실행할 프로젝트 명령이나 테스트 명령은 없습니다.

AI의 역할과 학습 완료 판단 기준은 [튜터 지침](AGENTS.md)에 있습니다. “다음 단계”, “도와줘”는 프로젝트 구현 대행 요청으로 취급하지 않습니다.

최종 제출 때는 이 저장소 안의 사용자 코드와 환경 정보로 재실행할 수 있어야 합니다. 현재 PC의 외부 참고 경로에 의존해 제출하지 않습니다. 모델 가중치·가상환경·API 키는 제출하지 않습니다.

## 환경에 관한 구분

발제의 공통 환경은 Windows, VS Code, uv, Python 3.12, Ollama입니다. 사용자가 선택한 실습 기준은 **현재 PC의 WSL2**이며, 환경을 직접 구성하고 차이를 기록합니다. 두 로컬 후보는 동일 PC·동일 실행 환경에서 비교합니다.

이전 AI 작업의 코드·설정·가상환경은 저장소 밖에 백업했습니다. 시스템 도구와 원본 예제는 유지했으며, 백업은 사용자 실습이나 제출 근거가 아닙니다.
