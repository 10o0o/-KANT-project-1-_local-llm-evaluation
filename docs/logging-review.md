# llama.cpp 기록 구현 점검

2026-09-16 AI의 구현과 모의 검증 결과를 참고했다. 실제 서버·모델·Cloud를 실행하거나 채점하지 않았다. 과거 코드는 `pre-cleanup-2026-09-15` 태그에 보존한다.

| 항목 | 현재 구현과 확인 경계 |
| --- | --- |
| 전체 응답 시간·입력·실패 | 성공·예외 양쪽 elapsed, 실제 messages, 요청 설정과 호출 오류를 저장한다. 자동 재시도는 없으며 실패를 성공 응답으로 대체하지 않는다. |
| 입력 처리·생성 통계 | 응답의 raw timings를 보존한다. 생성 시간이 0 이하이거나 필드가 누락되면 속도는 null과 사유로 기록한다. Ollama 나노초 단위와 혼용하지 않는다. |
| 서버 시작 시간 | 시작부터 첫 정상 health 응답까지 계측한다. 준비 확인 간격과 초기화를 포함하며 파일 해싱은 제외한다. 순수 가중치 로딩 시간이나 요청별 load_duration은 아니다. |
| 요청별 로딩 시간 | API에 대응 필드가 없어 model_load_seconds는 null과 미제공 사유를 기록한다. 별도 환경 기록의 server_startup_seconds와 연결한다. |
| VRAM | nvidia-smi로 준비 직후·응답/호출 실패 직후 관측한다. 프로세스와 전체 장치 메모리를 구분하고 출처·시점·MiB 단위를 남긴다. WSL 미지원은 null과 사유로 보존한다. 최대값이 아니다. |
| 실행 조건 | 세션별 환경 JSON·원본 서버 로그·종료 기록을 보존한다. 실제 실행 인수와 props/로그 관측값을 구분한다. GGUF·바이너리 SHA-256과 소스·패키지·장비 정보를 기록한다. |
| 환경 연결 | warmup/benchmark에 환경 JSON을 명시하고 모델·프로세스·포트·파일 상태·서버 정보를 요청 전 검증한다. 결과에서 환경 경로·세션·해시를 참조한다. |
| 캐시 | cache-ram 0과 별도로 공통 요청에 cache_prompt=false를 명시한다. |
| 워밍업 | 별도 입력·폴더·experiment.type으로 저장하며 본 실험에서 제외한다. 실행 성공 근거는 아직 없다. |
| 채점 | 기존 테스트별 판정·시간·원본 결과를 유지한다. 새 구현의 실제 모델·채점 실행은 미확인이다. |

실행 순서는 [README](../README.md)의 서버 시작 → 환경 기록 → 워밍업 → 두 회차 평가를 따른다. 측정 누락은 0으로 채우지 않고 지표별 집계 n을 표시한다. 기술 구현을 본 실험 준비 전체 완료나 학습 완료로 해석하지 않는다.
