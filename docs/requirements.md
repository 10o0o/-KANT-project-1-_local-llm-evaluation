## 사용 사례

유저가 특정 알고리즘 문제 설명 텍스트 또는 문서를 제출하면, 해당 문제 풀이에 대한 설명과 접근법 시간/공간 복잡도 및 설명,실행 가능한 Python 정답 코드를 제공한다.

## 난이도 범위

문제 난이도는 본인의 체감을 기준으로 1~10으로 구분한다. 외부 사이트의 공식 난이도를 환산한 척도는 아니며, 다음 세 수준을 기준점으로 삼는다.

- **1:** AtCoder ABC 초반~중반 문제 수준
- **5:** AtCoder ABC 중반~후반 문제 수준
- **10:** Codeforces Div.1 후반 문제처럼 FFT, 금광 세그먼트 트리 등의 고급 기법이나 깊은 수학적 지식, 게임 이론, 어려운 애드혹 발상이 필요한 수준

나머지 난이도는 이 기준점 사이에 체감에 따라 배치하고, 각 문제에 난이도를 부여한 이유를 짧게 기록한다. 특정 알고리즘의 사용 여부만으로 난이도를 결정하지 않는다.

# 제출 규칙

- 최초 생성 코드를 로직 수정 없이 제출하고, 코드 울타리 제거 등 형식 정리만 허용한다.
- 두 회차 모두 평가하며, 수정·추가 질문으로 개선한 결과는 분리한다.
- 유효 정답: AC이면서 실행 시간이 적용 시간 제한 미만인 답변이다.
- 유효 정답률: 유효 정답 수 ÷ 모델당 본 실험 20회입니다. 호출 실패·코드 미생성도 분모에 포함한다.
- 선정 순서는 유효 정답률 → 설명 정확성 → 모델 응답 속도이며, 일반 AC 비율도 별도로 기록한다.
